# Файлы для итогового задания

В директории `tests` находятся тесты для проверки API, которое должно быть реализовано в веб-сервере.

Директория `web` содержит файлы фронтенда.

Проект используется для управлениями задач. Добавление, удаление, редактирование и выполнение.
Выполненные задачи *:
-пароль из переменых окружения
-правило повторения (дни,недели).

Адрес в браузере:
http://localhost:7545/


Запуск:
go run .

Запуск через Докер:
docker build --tag go_fin:v2 .   
docker image ls
docker run -d -p 7545:7545 go_fin:v2
